# Bill Splitter
Fast, minimal, WhatsApp-first bill splitting app. Core promise: split a bill in under 30 seconds.

MVP: guest mode, manual split, receipt scan, AI extraction with Gemini, editable confirmation, equal/custom/item split, WhatsApp sharing.

Stack: React Native + Expo + TypeScript; Node.js + Express + TypeScript; Supabase PostgreSQL; Gemini API.
