# Bill Splitter
Fast, minimal, share-first bill splitting app. Core promise: split a bill in under 30 seconds.

The 48-hour MVP is guest mode with a dependable manual path: enter one total, add people, select equal or custom shares, review, and share through the native share sheet (including WhatsApp). Item splitting and receipt scanning are optional enhancements and must never block the manual flow.

Stack: React Native + Expo + TypeScript; Node.js + Express + TypeScript; Gemini API. Supabase PostgreSQL is a Phase 2 option for persistence, not a launch dependency.
